# 原始资料契约

所有机构、车辆、单据和设备均为本地合成，不来自新闻中的真实企业，也不声称新闻发生过这些事件。

inputs/versions.json列出提供方原始版本；它们是输入，没有共享净变化、传递包或接收仓。share-contract.json声明投影day/district/material/weight，筛选district in [A,B]，private_ticket不共享，也不得拿它当接收方主键。输出类型与NULL作为共享契约的一部分，精确小数不能转浮点哈希。重复行合法，以重数解释，减量不得使重数为负。
提供方生成的传递须表明共享契约、起止基线、传递身份及内容校验；接收方不得用文件名或抵达顺序推断基线。同一身份内容冲突中止，不自动挑一份；缺基线明确要求补传或重新建立完整基线。物理文件重排而行多重集不变属于无业务变化。
完整替换是新的基线代际，只有完整覆盖核验并对外开放后才能确认成功；旧代际差量不得继续应用，旧查询在替换构建期间不受半成品影响。提供方退休旧版本后不保证仍可计算那一基线的差量。筛选/字段/类型更改形成新共享契约，接收方明确接纳才生效。
传递可以经本地文件交接，不需要实际网络；应能在接收持久化和确认之间注入断点。两个仓分别保存自己的进度与查询结果，不把进程内变量作为已经收到的凭证。

seed.json与同名Parquet保存相同的输入值，actions.json中的后续动作尚未处理。inventory.json只校验原件物理完整性，不是仓库目录或业务结论。所有后续仓表与接口均待开发，源码不规定其架构。
